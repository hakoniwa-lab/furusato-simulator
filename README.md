# ふるさと納税シミュレーター MVP

額面年収・就業形態・扶養人数を入力するだけで、ふるさと納税で「実質2,000円」で寄附できる控除上限額の目安を計算するWebアプリ。HAKONIWA LAB([[takehome-calculator]]と同じ計算ロジックを土台にした)6本目のツール。ビルドツール不要のVanilla HTML/CSS/JS。

[[takehome-calculator]]で使った給与所得控除・社会保険料・所得税率表のロジックをそのまま流用し、そこに「控除上限額」の計算式を追加した構成。「手取り額が分かったら、次はふるさと納税の上限も知りたい」という自然な導線を作るため、takehome-calculatorの結果画面からもクロスリンクしている。

## ローカルでの動作確認

```
cd furusato-simulator
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。`index.html` を直接ダブルクリックしても動作する(外部通信は一切行わない)。

## ファイル構成

```
furusato-simulator/
├─ index.html          … 入力フォーム+結果表示のSPA本体
├─ css/style.css        … 他アプリと同じCSS変数デザインシステム(takehome-calculatorからコピー、フォーム/結果表示用スタイル込み)
└─ js/
    ├─ calculate.js       … 控除上限額の計算ロジック(純粋関数、DOM非依存)
    └─ app.js             … フォームの入力受付・DOM描画
```

## 計算ロジックについて

`js/calculate.js`の給与所得控除・所得税率表・社会保険料の簡易計算は、[[takehome-calculator]]の`js/calculate.js`と共通のロジック(コードは重複しているが、意図的に別リポジトリとして独立させている。将来共通化する場合は要検討)。

控除上限額は、**ワンストップ特例制度を利用しない場合**の一般的な速算式で計算している:

```
控除上限額 = 住民税所得割額 × 20% ÷ (90% − 所得税の限界税率×1.021) + 2,000円
```

- 住民税所得割額: `taxableIncomeForResidentTax × 10%`(均等割は含まない)
- 所得税の限界税率: 課税所得(所得税ベース)が該当する累進税率のブラケット税率(実効税率ではない点に注意)
- 1.021: 復興特別所得税(2.1%)を加味する係数

### 検証(2026-08-01)

会社員・独身・扶養0人・40歳未満のケースで、一般的なふるさと納税シミュレーターで引用される目安表と照合済み:

| 額面年収 | 本アプリの算出 | 一般的な目安 |
|---|---|---|
| 300万円 | 29,040円 | 約28,000円 |
| 400万円 | 43,001円 | 約42,000円 |
| 500万円 | 61,982円 | 約61,000円 |
| 600万円 | 78,340円 | 約77,000円 |
| 700万円 | 109,450円 | 約108,000円 |
| 800万円 | 131,083円 | 約129,000円 |
| 1000万円 | 178,659円 | 約176,000円 |

いずれも誤差1〜2%程度で近似できている。

**注意**: 医療費控除・住宅ローン控除・iDeCo拠出等、他の所得控除・税額控除がある場合は実際の上限額が変わる。ワンストップ特例制度を利用する場合(確定申告不要、寄附先5自治体以内)は住民税からのみ控除される点も、本シミュレーターでは考慮していない(上限額の計算式自体はワンストップ特例でも同じだが、控除される税目の内訳が異なる)。年度が変わったら税率表・保険料率を再確認すること。
